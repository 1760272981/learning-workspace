## 一、自我介绍

〈学校 / 专业 / 年级；团队 1–3 人姓名与分工；赛道：StudyHack 学习科研〉
我们是〈…〉，平时用 AI 辅助做课程项目和个人项目。这次想解决"用 AI 学东西，但学完不会判断、验收"的问题。

## 二、你的作品是什么（一句话）

Learning Workspace 是一个给"用 AI 做项目的大学生"的学习工作台：把每一次 AI 产出用「三问」拆成可验收的知识，长成一棵可标记、可回顾、可验收的知识树；智能来自使用者自己的 agent，壳可以搬回自己电脑跑。

## 三、为什么做

- 真实痛点：AI 给的答案看完就忘，下次仍不会判断它对不对、能不能用；"读懂了"不等于"会验收"。
- 想法来源：把学习的单位从"知识点"换成"一次具体判断/验收"。每条知识必须回答三问——现在要判断什么、产出里有什么证据、学完能亲自做什么验证动作；答不出就不进树。
- 取舍：宁可本轮推荐为零，不凑数；每个产出版本最多 2 条、每项目每天最多 3 条，优先误判后果大、马上要用的。
- 分发取舍（负责人拍板）：不让所有人挤在我们的云上——壳搬回家、数据留本地；我们的云只留评委沙箱和 own 真实树展示窗。多用户隔离用平台新机制（私有数据库凭证），每人令牌绑自己的 agent。

## 四、怎么用（5 步，评委照着即可用起来）

1. 打开沙箱 https://learning-workspace-multi-v5d3qx7uw3a.qoder.zone ，看入口页三条路；用演示账号 demo / demo-2026 登录（或注册自己的）。
2. 点「记录一条知识」：标题 + 三问 + 至少一条真实来源链接，提交入树（缺证据会被拦下并提示补哪项）。
3. 刷新页面确认还在；点叶子看三问与来源；标记「我理解了 / 暂时跳过」，写一条验收记录保存。
4. 想绑自己的 agent：在「我的令牌」创建个人令牌，贴进自己 agent 的 MCP 配置（LW_API_BASE + LW_USER_TOKEN），agent 提交的学习点直接长在你的树上。
5. 想搬回家：入口页复制整段提示词给你的 agent，或克隆仓库 `npm install && npm run local`——纯本地、不登录、数据在自己文件里。

## 五、用 Qoder 做出来的过程（哪几步交给它、我改了什么）

交给 Qoder 的：
- 前端整体实现与多轮重做：React+Vite+Tailwind 的"消消乐式藤条知识树"（纯 SVG 样条）、详情面板、提交表单、响应式与无障碍。
- 数据层与规则单一来源：shared/model.ts（三问校验、四态返回、上限、幂等、概念与应用分离），Web/MCP/云函数共用。
- 本地 MCP 提交工具 submit_learning_block + 主动触发 Skill learning-capture（平时编码不打断）。
- 地基探针：先验平台权益/网关/数据库/发布链路（探针 A 四项真实请求），再建产品；失败不连环重试、查状态再定。
- 云端闭环与多用户：云函数五动作+幂等对账；密码登录实验室改造（会话/限流/哈希）、owner 隔离、个人令牌；function_backend 新站迁移八表+发布+25 项真实验收。
- 本地壳 kit：文件库原子写、本地服务、MCP 与网页同库、配置提示词单一来源、仓库打包。
- 工程兜底：TypeScript 全量检查、21 项 MCP 自测、12 例评估、29 项函数测试、5 项云端契约、跨进程硬指标、浏览器 QA。
- 协作方式（负责人定）：主会话规划写任务书 → 子代理（HungerG）执行本地代码 → 主会话亲自复跑验收；云端每步写入先报备再动手。

我（负责人）改/拍板的：
- 产品红线："必要，不是什么都塞"；以判断/验收为中心；不造假演示数据。
- 三问字段与上限数值；"已会就跳过、缺证据就问一个具体问题"的交互。
- 艺术方向与树的形态取舍（否掉多版方案，选定藤条果实）。
- 范围决策：多用户现在做（评委沙箱）+ 分发改纯本地搬回家（GitHub）+ 教学 Agent 挪赛后；旧站匿名读+写的残余风险知情拍板。
- 逐轮验收：每版由我在真实浏览器/真实请求确认后才进入下一步。

## 诚实披露（写进帖子里，不藏）

- 开发机无 Deno，函数未做本地类型检查；运行时正确性以部署后真实请求验收为准。
- 旧站为平台 legacy 机制，匿名读+写是知情拍板的限期测试授权，隔离边界未验、非生产安全保证；评委沙箱用新机制私有凭证，无此残余。
- 多行写入非事务、文件库非跨进程事务：靠确定性 ID+唯一键+对账防重复，不承诺强原子。
- 无邮箱验证/找回密码/OAuth/云同步（本期边界，赛后升级）；教学 Agent 本期未做。
- 平台遗留：旧站一个探针 Secret 删除被平台阻塞（已记录 requestId），不影响使用。
